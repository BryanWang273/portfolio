WineVault

A full-stack wine marketplace with an aging tracker. Browse wines and check out through a cart flow, then follow each bottle in your cellar against an estimated drinking window, with tasting notes. 02

Restaurant Management System

A full-stack restaurant platform — FastAPI + PostgreSQL backend, Next.js frontend — with an AI inventory agent that turns raw consumption data into reorder recommendations. The core design decision: Python owns every number, the LLM only ever reasons over pre-computed summaries via a bounded tool-calling loop.

  • PostgreSQL
  • Next.js
